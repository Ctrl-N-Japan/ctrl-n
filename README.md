# ctrl-n

プログラミングチーム **Ctrl-N** の公式Webサイトのリポジトリです。
現役高校生が中心となって共同開発・運営を行っています。

---

## 🛠️ プロジェクト概要
チームの公式サイトを新規構築するプロジェクトです。
まずはシンプルな構成からスタートし、徐々にコンテンツを拡張していく予定です。

## 👥 メンバー構成
- **現役高校生メンバー**（未来の凄腕エンジニアたち）
- **OBメンバー**（頼れる先輩エンジニアたち）

## 📝 開発について（Contributors）
- **Issueベースの開発:** 機能追加やバグ報告は、すべてGitHubのIssueを活用して管理しています。
- **コードレビューの実施:** 原則として、メンバーによるレビューと承認を経てからメインブランチへ統合します。
- **オープンソース:** チーム内での合意形成に基づき、透明性の高い開発を目指しています。
