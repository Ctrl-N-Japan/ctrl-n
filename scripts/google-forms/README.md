# Googleフォームからプロフィールを掲載する

1. https://script.google.com/ で新しいプロジェクトを作り、`setup.gs` を貼り付けます。
2. `createProfileForm` を実行し、Googleの権限を許可します。ログにフォーム編集URL・回答URL・回答シートURLが出ます。再実行では重複作成しません。
3. フォーム編集画面で「作品画像」という質問を追加し、種類を「ファイルのアップロード」にします。画像のみ、最大3枚、1枚1MBに設定してください。ファイルアップロードには回答者のGoogleログインが必要です。サイトで扱う形式はPNG/JPEG/WebPです。
4. テスト回答を送信した後、`exportApprovedProfiles` を実行します。回答シートに「掲載OK」列が追加されます。
5. 確認済みの行の「掲載OK」をチェックします。同じGitHubユーザーの回答が複数ある場合、掲載する1行だけチェックしてください。フォームのユーザー名入力だけでは本人確認にならないため、管理者が本人・画像・掲載内容を確認します。
6. `exportApprovedProfiles` を再実行し、ログのDrive URLからJSONをダウンロードします。回答シートやDriveの共有設定を公開する必要はありません。
7. ローカルで次を実行します。

```sh
node scripts/import-member-profiles.mjs ~/Downloads/ctrl-n-approved-profiles.json
bash local-build.sh --build
```

インポートは掲載OKの一覧全体をプロフィールJSONに置き換えます。チェックを外したプロフィールは次回の取り込みで非掲載になります。公開メンバー以外のユーザー名、不明なテーマ、不正な画像は取り込みを停止します。メールアドレスなど、掲載項目以外は書き出しません。回答のJSONそのものはリポジトリへ追加しないでください。

公開データは `assets/data/member-profiles.json`、画像は `assets/images/members/` へ保存します。フォームのテーマ名は既存の75テーマや `auto` / `auto-season` / `auto-time` を指定できます。空欄なら既存設定を保ちます。フォーム未回答のメンバーも通常の一覧には残ります。

更新を確認してコミット・pushすれば、サイトの公開手順に沿って反映できます。現在は管理者が確認して取り込む方式で、自動連携はしていません。
